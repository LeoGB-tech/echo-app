Écho sur Oracle

Ton serveur gratuit de 200 Go pour toute ta musique · environ 20 minutes, une seule fois

1

Créer le compte Oracle Cloud

  • Va sur signup.cloud.oracle.com.
  • Région d'origine : choisis France Central (Paris) ou France South (Marseille). Elle ne peut plus être changée ensuite.
  • Oracle vérifie une carte bancaire (empreinte de 1 € environ, remboursée). Le compte doit être au nom d'un adulte : fais-le avec un parent.
  • Reste sur l'offre gratuite : tant que tu ne cliques pas sur « Passer à un compte payant », rien ne peut être facturé.
2

Copier le script d'installation

Ce script installe tout tout seul (serveur Écho, HTTPS, pare-feu).

Télécharger

3

Créer la machine

  • Dans la console Oracle : menu ☰ → Compute → Instances → Create instance.
  • Name : echo.
  • Image → Change image → Canonical Ubuntu 24.04.
  • Shape → Change shape → Ampere → VM.Standard.A1.Flex, 1 OCPU, 6 Go de mémoire (marqué « Always Free-eligible »).
    Si Oracle dit « Out of capacity » : réessaie plus tard, change de « Availability domain », ou prends VM.Standard.E2.1.Micro (aussi gratuit).
  • Networking : laisse « Create new virtual cloud network » et « Assign a public IPv4 address » cochés.
  • SSH keys : « Generate a key pair » puis Save private key (à garder, utile seulement en cas de souci).
  • Boot volume : coche « Specify a custom boot volume size » et mets 200 Go (le maximum gratuit).
  • Show advanced options → onglet Management → « Paste cloud-init script » → colle le script copié à l'étape 2.
  • Clique Create.
4

Ouvrir les ports 80 et 443

  • Sur la page de ta machine, dans Primary VNIC, clique sur le lien du Subnet.
  • Onglet Security (ou « Security Lists ») → Default Security List… → Add Ingress Rules.
  • Source CIDR : 0.0.0.0/0 · IP Protocol : TCP · Destination Port Range : 80,443 → Add Ingress Rules.
5

Brancher Écho

  • Attends 5 à 10 minutes que l'installation se termine.
  • Copie la Public IP address affichée sur la page de la machine (par ex. 141.145.12.34).
  • Dans Écho : Réglages → Stockage Oracle → colle l'adresse → Enregistrer et tester.
  • Puis Transférer mes morceaux vers Oracle : laisse Écho ouvert sur le PC pendant le transfert. Chaque morceau est vérifié sur Oracle avant d'être supprimé de Supabase.

Ensuite, tous les nouveaux morceaux iront directement sur Oracle (sans limite de 50 Mo par fichier).

Bon à savoir

  • Oracle peut arrêter une machine gratuite qui ne fait presque rien pendant 7 jours. Si Écho n'arrive plus à lire tes morceaux : console Oracle → ta machine → Start. Tes fichiers ne sont pas perdus.
  • Un parent peut aussi passer le compte en « Pay As You Go » : les ressources gratuites restent gratuites et la machine n'est plus arrêtée, mais tout ce qui dépasse l'offre gratuite serait facturé. Ce n'est pas obligatoire.
  • Ta musique n'est accessible qu'avec ton compte Écho : chaque lien de lecture est signé et expire au bout de 12 h.
